## Global Constraints

- **单一真相 `world.locale`**：UI locale 复用同一值（全局一种语言）；改语言（含顶栏切换器）会 reload 插件 + 改 bot 输出语言（已披露采纳）。

- **zh 零回归**：zh-CN 词典每值 = 抽键前该处中文串**逐字节相同**；多子句 concat 每片模板 = 原片字面。
- **键集三语相等 + 占位符集相等 + 数据层键覆盖**（三道测试网，见 T1/T2）。
- **单文件产物铁律**：词典**静态 import**（禁运行时 fetch / 动态 `import()`）；`verify:bundle` 恰 1 .js；`build`（vite + `normalize-eol.mjs`）后**重建并提交 `pages/settings` 产物**（CI `git diff --exit-code -- pages/settings` 须绿）。词典 UTF-8+LF。
- **严禁删 schema.ts / `_conf_schema.json` 键**；PAL_TREE 保持可 `json.loads` 数组结构（后端 `test_frontend_tree_matches_backend_meta` 锚）；`schema.test.ts:57` locale optionLabels 恒定不译锁不可破。
- **响应性**：凡 `<script setup>`/模块作用域 `const` 缓存的可见文案 → `computed`/getter/模板即时 `t()`，禁把 `t()` 冻进 const。`Field.vue` `SelectRoot` 绑 `:key="locale"`（关闭态触发器随切）。

- **dev-only 排除** `src/dev/**`。
- commit 不含 Claude 署名；子代理一律 opus。

```ts
// frontend/src/lib/i18n.ts
import { ref } from 'vue'
import zhCN from './locales/zh-CN'
import ja from './locales/ja'
import en from './locales/en'

export type Locale = 'zh-CN' | 'ja' | 'en'
const SUPPORTED: readonly Locale[] = ['zh-CN', 'ja', 'en']
const DICTS: Record<Locale, Record<string, string>> = { 'zh-CN': zhCN, ja, en }

export const locale = ref<Locale>('zh-CN')          // 模块顶层不猜；默认 zh-CN

export function guessLocale(): Locale {
  const l = (typeof navigator !== 'undefined' && navigator.language) || ''
  if (l.startsWith('ja')) return 'ja'
  if (l.startsWith('en')) return 'en'
  return 'zh-CN'
}

export function setLocale(l: unknown): void {
  if (typeof l === 'string' && (SUPPORTED as readonly string[]).includes(l)) locale.value = l as Locale
  // 否则 no-op（保持当前）
}

export function t(key: string, vars?: Record<string, string | number>): string {
  const s = DICTS[locale.value][key] ?? DICTS['zh-CN'][key] ?? key
  if (!vars) return s
  return s.replace(/\{(\w+)\}/g, (m, k) => (k in vars ? String(vars[k]) : m))  // 缺参留原样
}
```
