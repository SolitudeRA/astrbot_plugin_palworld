# i18n Phase 3 · 三语文档与可复现截图实现计划

> 日期：2026-07-28

## Goal

保持中文 `README.md` 为 GitHub 默认入口，为 README、配置、命令、贡献指南提供完整的 zh-CN/ja/en
平行版本；为三语 README 生成 18 张来自同一 source commit、同一语义演示数据和固定 scale 的正式 PNG，
并用结构、链接、技术 token、manifest、哈希与人工视觉验收共同守门。

## Architecture

- 文档层：12 个显式文件组成 4 个文档族；中文是事实规范源，三语同章节共享稳定英文 anchor ID。
- 测试层：`tests/unit/docs_i18n_test.py` 使用显式 manifest，按文档族/稳定章节验证结构、链接、表格和
  技术 token，不跨文件聚合抵消。
- 设置页截图：`scripts/capture_docs_assets.py` 启动锁版本 Vite + Playwright/Chromium，
  `frontend/scripts/capture-docs-screenshots.mjs` 在全新 browser context 中按 capture manifest 生成 12 张 PNG。
- 图片名片：`scripts/export_docs_cards.py` 用真实 `build_me_card_html` 生成三语 HTML，再由同一锁版本
  Chromium 以生产等价 Jinja→HTML→PNG 契约生成 6 张 PNG。
- 资产证明：`docs/images/screenshots.manifest.json` 记录 source commit、工具版本、场景、主题、viewport、
  DPR、zoom、像素尺寸与 SHA-256；CI 校验 manifest，不做跨平台像素 diff。

## Global Constraints

- 不修改已有中文标题文本；在每个 H1–H3 前加入 `<a id="stable-id"></a>`，仓库内 fragment 全部迁移到显式 ID。
- 每份文档 H1 后紧跟 `简体中文 | 日本語 | English`；当前语言加粗且不可点击，其余使用相对链接。
- 英文和日文不是摘要版；危险操作、安全告知、PII、默认关闭、仅管理员、审计与降级语义不得弱化。
- `/pal` 路径、子命令、枚举、配置键、endpoint、环境变量和真实输入别名 `卡`/`图` 保持；说明性
  metavariable 可翻译为 `<name>`、`<player>` 等。
- Phase 1/2 运行时文案校对白名单初始为 **空集**。截图目检若发现明确错误，先把精确 locale key、理由和
  回归测试补入本计划，再修改词典；不得顺手改写。
- capture mode 仅存在于 `frontend/dev.html`/`frontend/src/dev/**`，不进入生产 bundle。
- 正式设置页截图固定 zoom 100%、DPR 2；常规 viewport `1100×960`，onboarding `1100×600`。
- 名片固定 renderer `zoom: 2` 和原生宽度 `1008px`；高度由各 locale 自然内容决定，禁止裁切、补边、重采样。
- source commit 必须是生成图片前已提交的仓库状态；生成后的 PNG 与 manifest 单独提交。
- 不提交真实服务器、账号、群、Token、密码、审计或 PII；fixture 只用 `example.com` 与中性标识。
- commit 不含 AI/Claude/Codex 署名。push/PR 前按用户约定展示目标、分支、标题、正文、diff 与验证并等待确认。
