# i18n Phase 1（后端聊天 + 图片卡 + 元数据三语）实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans 逐任务实现。步骤用 checkbox（`- [ ]`）跟踪。
> **需求真源**：`docs/superpowers/specs/2026-07-26-i18n-trilingual-design.md`（已过四棱镜对抗复核，30 发现落改）。每任务 brief 随附该 spec 路径——**收编方式/键名/结构/豁免以 spec 对应 §节为准**，本计划给任务边界、TDD 循环与接口。

**Goal:** `world.locale ∈ {zh-CN, ja, en}` 全局生效：聊天输出、图片名片、规则措辞、帕鲁名、图鉴、help 全量三语；zh-CN 端到端输出逐字节不变。

**Architecture:** 方案 A——`L(key, **kw)` 签名不变，`locale.py` 改装载器（`MESSAGES`=zh 基线恒驻 + `_ACTIVE` 按 locale 装载 + fallback 链）；application/shared 泄漏**稳定键化**上提 presentation；metadata 单文件多语字段；dex 展示名查询时现解。

**Tech Stack:** Python（AstrBot 插件，相对导入）+ JSON locale 文件 + Workflow 批量翻译/回填。

## Global Constraints（每任务隐含）

- 包内相对导入；locale JSON **按包位置解析**（`Path(__file__).parent / "locales"`），绝不 data_dir/CWD。
- **零回归两档锚（spec §6）**：档一=端到端输出中文锚原样全绿；档二=显式迁移面（`locale_test.test_missing_key_raises`、HELP_TEXT 两测试、`query_service_status_test:80`、report/name_resolver 等 application 直断中文的单测）**同 commit 改锚稳定键**，除此之外不许动任何现有断言。
- application/shared **禁止向上取 `L()`**（分层契约）；收编=下层产稳定键、中文上提。
- `MESSAGES` 公开名恒驻（zh 基线，import 时装载、永不随 `load_locale` 重绑）——3 个 `import MESSAGES` 测试零改动。
- zh-CN.json 键值与现行措辞**逐字一致**；键命名 snake_case 语义前缀（spec §3.5）。
- config_view 三白名单铁律：本工程仅动 `_ENUMS`；`config.py:475` locale 解析**保持裸透传**（`load_locale` 是唯一校验/回落/warning 点）。
- 产物 `pages/settings` 只经 `cd frontend && npm run build` 重建；提交信息不含 Claude。
- 测试命令：`./.venv/Scripts/python.exe -m pytest -q` + `ruff check .` + `mypy palworld_terminal` + `lint-imports`；前端 `npx vitest run` + `npm run typecheck`。
- 版本号不 bump。
